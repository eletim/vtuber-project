# 羽月こま 表情PSD v8

## 実施
- PSD v7の49レイヤーを保持し、閉じ目（左右）・閉じ口レイヤーのみを承認済みの表情素材に置き換え。
- 2つの閉じ目レイヤーと閉じ口を独立して表示/非表示可能。閉じ口は重なり順の最上層に修正。
- 初期表情は元の確定画像とピクセル単位で一致。4つの表情状態を実際にPSDを読み直して検証。
- Photoshopレイヤー名 `.closed` は初期非表示。表情変更時は対応する `.closed` レイヤーを表示すると、下の開いた目・口を覆う構造。

## 検証
- 49レイヤー再読み込み成功
- 初期表情RGB差分0画素、アルファ差分0画素
- 4状態でレイヤー範囲外のRGB変更0画素、透明穴0画素
- 4状態をPSDから再合成した画像と書き出しプレビューが一致

## 再生成
```
python -m pip install -r requirements.txt
python scripts/repair_expressions_v8.py
```

## 制約
これは表情差分のPSD素材を修正した段階です。まばたき・口パクは現状スプライト切替で、Live2D Cubismのメッシュ・パラメータ変形はまだ未実装。髪や衣装の下地の美術的な補修も残っています。
