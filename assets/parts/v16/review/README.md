# v16 mouth regression evidence

This compact recovery commit keeps the final review reports, all 240 numeric alpha checks, original-file preservation hashes, the runtime benchmark, the corrected MP4, and its encoded before/after mouth comparison.

The full before/after/threshold PNG matrix is retained separately in `koma-v16-visual-audit.zip` (the `final_review_bundle` directory). Paths in `FINAL_REVIEW.md` and `FINAL_REVIEW.json` refer to that archive. Reproduce all matrices with the checked-in scripts and instructions in `scripts/review_mouth_v16/RERUN_REVIEW.txt`. The full-frame video pipeline is in `scripts/video_v16/RERUN.txt`.

Browser GUI E2E, real camera/microphone, OBS, and Photoshop application operation were not exercised in this environment. The existing artwork and PSD were not edited.
