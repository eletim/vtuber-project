# VTuber Project — 羽月こま

将棋をテーマにしたLive2D VTuberを制作するプロジェクトです。将来は人間による操作とAIによる操作を切り替えます。

## 現在の制作段階

確定したキャラクター画像から、顔・目・口・髪・衣装などを大まかな領域に分割した **26レイヤーのPSD初稿**を制作中です。現段階は自動パーツ分割の試作であり、Live2D Cubismで自然に動かすための描き足し・境界修正・表情差分・メッシュ設定は未完了です。

## 方針

- できる限り無料のツールを使用
- AIおよびスクリプトを活用し、手作業を最小化
- キャラクターデザインは確定。新たなデザイン生成は行わない
- PSD → Live2Dモデリング → 人間モード/AIモードの順に制作

`assets/original/` には確定画像を、`assets/parts/` には生成したPSDおよびPNG素材を配置する想定です。画像・PSDなどの大容量バイナリは必要に応じてGit LFS等で管理します。
