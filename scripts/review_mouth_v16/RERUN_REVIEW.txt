Reproduce the v16 mouth audit without modifying production runtime or art

Dependencies: Python3, Pillow, NumPy, Node.js, libEGL.so.1, libGL.so.1,
Mesa llvmpipe (or another working offline EGL implementation), ffmpeg,
and DejaVu Sans fonts. No browser, local-file navigation, or Chromium is used.

The scripts may be copied together into scripts/review_mouth_v16/. Run from
any working directory, using the chosen scripts directory in each command.
The repository must contain the final eight-expression runtime, the original
assets/parts/v13/koma-free-voice.wav, and the frozen v16 JS helper.

1. Snapshot the runtime into this review-script directory:
   python scripts/review_mouth_v16/prepare_source.py --source /path/to/repository

   This prepare_source.py is the original compatible video_v15 snapshot tool.
   It writes source/runtime, audio fixture files, and source-provenance.json
   beside itself. It verifies all runtime source hashes before/after copying.
   Production runtime/model PNGs are never modified.

2. Export straight RGBA source fixtures from the snapshot PNGs:
   python scripts/review_mouth_v16/prepare_review_assets.py

3. Call the actual snapshotted runtime JS helpers for all240 cases:
   node scripts/review_mouth_v16/generate_review_grid.mjs

   Output: grid.json, grid-mesh.bin, and exact deformMouthPixels RGBA patches
   plus width/height metadata under source/runtime/model/review_textures/.

4. Convert generated straight RGBA to PNG for the unchanged EGL uploader:
   python scripts/review_mouth_v16/convert_review_textures.py

5. Render the controlled full-face matrix with original shared body mesh:
   python scripts/review_mouth_v16/render_review_grid.py

   The default output directory is generated/ next to the review-script
   directory. It retains all240 individual full-face and mouth images, all8
   standard matrices (21cases each), all8 threshold matrices (9cases each),
   and per-case mouth alpha statistics. Standard openings are
   0,.15,.20,.25,.35,.65,1; extra openings .141,.16,.214. Head Z is -8,0,+8deg.

Implementation provenance:
- render_review_grid.py initializes the original video_v15 EGL source-over
  compositor from the included render_v15.py, stopping before video encoding.
- Mouth PNGs are generated by actual deformMouthPixels, not a Python re-write.
- The old featureBands result is disabled for every new pre-warped mouth.
- Source PNGs are uploaded premultiplied, composites stay premultiplied, and
  output is unpremultiplied only once for PNG inspection.
- All remaining runtime geometry and authored texture files are unmodified.
- This is offline EGL verification, not browser E2E or screen recording.
