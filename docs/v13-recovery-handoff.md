## 最初に試す

Python 3.10以降とChromeまたはEdgeを使用します。

1. リポジトリの v13 ブランチ、または添付の実行用ZIPを展開し、そのフォルダをターミナルで開きます。
2. リポジトリでは `python -m pip install -r requirements.txt`、実行用ZIPでは `python -m pip install -r requirements-runtime.txt` を実行します。
3. `python scripts/run_runtime.py` を実行します。最初だけ顔追跡用のファイルをネットから取得し、SHA-256を照合します。
4. Chrome/Edgeで `http://127.0.0.1:8766/` を開きます。終了はターミナルで Ctrl+C。

Windowsで `python` が見つからなければ `py`、macOS/Linuxでは `python3` に置き換えてください。

## 音声エンジンがなくても確認できること

- 「AI」で待機中の首・身体の揺れを確認できます。
- 「発話の雰囲気」を選び、「仕草を試す」で4秒の仕草を確認できます。修正版では人間モードからもAIへ切り替えて動作します。
- 「自然な動き」で追加の首・身体の動きを切り替えられます。呼吸・自動まばたきは別です。
- 「音声ファイルでリップシンク」から同梱の `samples/koma-free-voice.wav` を選ぶと、保存済み日本語音声を再生し、実音量に合わせて口が動きます。リポジトリ版では `assets/parts/v13/koma-free-voice.wav` が同じ音声です。
- 人間操作へ戻すと、AIデモと再生を止めて通常姿勢へ戻ります。

## 新しい文章をしゃべらせる

[公式VOICEVOX](https://voicevox.hiroshiba.jp/)をインストールして起動したまま、「読み上げ」を押してください。既定は `http://127.0.0.1:50021`、仮の声は「雨晴はう／ノーマル」です。VOICEVOXが未起動の場合はエラー案内が出ます。

音声の自動再生が止められたら画面内の音声プレーヤーで再生してください。操作画面を一つ開いたまま、OBSのブラウザソースでは `http://127.0.0.1:8766/?overlay=1` を指定します。OBS側は音声を重ねて再生しない設計なので、音声の取り込み先は別途設定が必要です。

音声クレジット：VOICEVOX:雨晴はう。配信・動画公開時にもこのクレジットを記載してください。利用条件は `docs/free-voice-v12.md` の公式リンクを確認してください。
