# 羽月こま v21: ローカル会話AIの接続準備（未設定）

この保存時点では、実モデルの導入許可を待っているため、モデルのダウンロード・起動・実返答の検証は行っていません。模擬サービスによる経路と停止・エラーの検証が完了した準備版です。

v20の「入力した文章をそのまま読む」とは別に、質問から短い返答を作り、その返答をVOICEVOXで読み上げる経路を追加しました。画像・PSD・身体の分離・顔と口の描画は変更しません。

## 未設定では生成しません

起動するだけでモデルのダウンロードや外部APIへの送信を始めることはありません。ローカルモデルが未設定・未起動なら、その状態を表示して「AIに話しかける」を無効にします。直接の文章読み上げは引き続き別ボタンで使えます。

会話の接続先は認証情報のないループバックHTTPだけです。APIキー、クラウド推論、有料サービス、リモートURLは使用しません。現在の画面は会話モデルへPC操作などのツールを渡しません。

## 操作

1. 音声エンジンと会話AIの接続を確認します。
2. 会話欄に質問を入力し、AIに話しかけます。「考え中」→「音声を作成中」→実際の再生へ進みます。
3. 質問と返答は別に表示します。口・表情・仕草は返答の音声再生に連動します。
4. 停止ボタンは返答を考えている間も音声合成中も使えます。遅れて届いた古い結果は再生しません。
5. 履歴を消すと、このサーバー起動中だけ保持する短い会話履歴を消し、進行中の会話も止めます。

入力は500文字、返答は300文字までです。履歴は最大2往復・合計1000文字の短い文脈で、ファイル保存しません。古い文脈は落とします。長文相談や長期記憶を備えた対話ではありません。

## 既存のローカル llama.cpp を使う

ローカルの llama.cpp server を、モデルに別名 koma-qwen3-1.7b を付けて127.0.0.1:8081で起動します。下記の環境変数を、この起動コマンドのプロセスにだけ設定してください。

- KOMA_LLM_PROVIDER=llamacpp
- KOMA_LLM_URL=http://127.0.0.1:8081
- KOMA_LLM_MODEL=koma-qwen3-1.7b

そのうえで `python scripts/run_runtime.py --text-only` を実行します。VOICEVOXも別途起動してください。/health と /v1/models を確認し、設定したモデル名が一致する場合のみ文章を送ります。自動で別モデルへ置き換えません。

Ollamaの既存ローカルサービスにも、明示設定した場合だけ対応します。今回の自動導入ではOllamaを使いません。Ollamaは起動時に固有鍵を自動作成するため、不要な認証情報を作らない llama.cpp を選びました。

## 必要な場合だけ公式の無料エンジン・モデルを導入

この同梱セットアップはLinux x64・Python3.12以降向けです。約1.85GBのダウンロードと、モデルを含む数GBの空き容量が必要です。モデルは同梱していません。Windows/macOSでは適合する公式 llama.cpp とモデルを用意するか、既存のローカルサービスを使います。

- `python scripts/setup_local_model.py --show-plan` で固定した公式URLとハッシュを確認できます。このコマンドは何もダウンロードしません。
- 必要なときだけ `python scripts/setup_local_model.py` を実行します。
- `python scripts/run_runtime.py --text-only --voicevox --local-model` で、導入済みのVOICEVOXとローカルモデルをまとめて起動します。

後者はダウンロードしません。エンジンをプロジェクト内から起動し、このコマンドを終了したときには自分で起動した子プロセスだけを停止します。システムへのサービス登録やアカウント作成、APIキー作成は行いません。モデルサーバーはオフライン指定、127.0.0.1のみ、Web UI・エージェント機能無効、CPU4スレッド、4096コンテキストで起動します。

## 検証の区別

自動テストの模擬会話サービスは、API・停止・重複・履歴・エラーの検証用です。これだけでは「実際のAI返答を確認した」とはしません。実モデルでの日本語の返答・音声化は、実行記録が付属している場合に、その記録で確認してください。

許可された実ブラウザの操作経路がないため、GUIと物理スピーカーの通し確認は未実施です。オフライン動画をブラウザ操作録画とは扱いません。小型ローカルモデルは誤答することがあり、事実確認や重要な判断の代替にはなりません。

実行ZIPを作る場合は `python scripts/package_runtime_v21.py /path/to/new-output` を使います。core/modelの2つを同じフォルダーへ展開します。付属samplesはv20の直接読み上げ検証音声であり、AIが生成した返答ではありません。
