# 羽月こま PSD v7 — 描画済みの下地への置換（作業版）

2026-10-18 時点の状況です。

## 実施したこと

- 確定した立ち絵は変更せず、v6のPSDへ実際の描画素材を組み込んだ。
- 以前に制作した「前髪なし」のイラストを位置合わせし、前髪・横髪・頭頂・髪飾り・首・手の下地に使用。
- 肌・腕・服の内側・ブラウスの続き・陰影を個別の描画として追加。
- 誤分類された前髪の3786画素を可動側に移動。
- 前髪やベストが動いたとき用の非表示レイヤーを追加。
- 旧v6のベースレイヤー8種のほぼ全画素を確定画像または新しく描いた素材に置き換えた。

## 機械的な監査

- 49レイヤーのPSDを独立読み込みできた。
- 元の初期表示とのRGB差分0画素、α差分0画素。
- 初期表示と7種類の部位非表示／切替状態で透過穴0件。
