# 羽月こま v16: 口の向き・輪郭の修正

## 修正内容

旧動画の 6〜7 秒・12〜13 秒などで問題を再現しました。旧処理は口を画面の縦方向だけに圧縮していたため、描かれた斜めの唇が水平へ近づいていました。暗い口角や口内も細い帯へ圧縮され、黒い破片のように見える箇所と矩形の下地境界が生じていました。これは動画圧縮の前から発生しており、該当領域の透過穴が原因ではありませんでした。

v16 は唇の向きに合わせた局所座標と、各表情の描かれた閉じ口の曲線を使います。口角の位置関係を保ち、閉じ際は閉じ口と対応させ、縮小時は複数の画素を平均して細い暗部のちらつきを抑えます。実行版と動画は同じ変形関数を使用します。

## 起動

Python 3.10 以降と、WebGL 対応の Chrome / Edge を使用します。

1. 実行用 ZIP を展開し、`koma-v16-runtime` フォルダーでターミナルを開きます。
2. `python -m pip install -r requirements-runtime.txt` を実行します。
3. `python scripts/run_runtime.py` を実行します。
4. ブラウザーで `http://127.0.0.1:8766/` を開きます。

macOS / Linux で `python` が見つからない場合は `python3`、Windows では `py` を使ってください。初回のみ顔追跡のモデル / WASM を取得し、固定した SHA-256 で検証します。カメラ・マイクはボタンを押したときだけ開始します。

## まず試す

- 「表情」から通常・微笑み・にっこり・困り顔・驚き・照れ・不満・考え顔を選びます。手動選択は画面に表示した 30 秒間有効です。
- 表情の切り替えは短いまばたきの閉じ際に行います。顔全体の半透明クロスフェードは行いません。
- まばたきは表情ごとに描いた開眼・閉眼の 2 状態を短いタイミングで切り替えます。まぶたの連続変形ではありません。眉や前髪を巻き込んでつぶさない方法を選びました。
- 口は描かれた唇の向きを保ち、その向きに対して垂直な方向へ開閉します。小さい開きでは描かれた閉じ口を使い、口の中の暗部を細い横線へ押しつぶさない方法に変更しています。顔全体を縮めたりつぶしたりはしません。
- にっこりの目は、元の笑顔の意図に合わせて閉じたままです。口パクは動きます。
- 「音声ファイルでリップシンク」から `samples/koma-free-voice.wav` を選ぶと、保存済み日本語音声を実際に再生し、その音量に合わせて口が動きます。
- 「AI」の待機中は呼吸・首・身体の揺れがあります。発話には発話の仕草が付きます。
- 人間操作への切り替え、リセット、再生停止では前の制御が残らないようにしています。

音声がブラウザーの自動再生制限で止まった場合は、画面内プレーヤーの再生ボタンを押してください。

## 新しい文章の読み上げ

[VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/)からエンジンを導入し、起動したまま画面の「読み上げ」を押します。既定の接続先は `http://127.0.0.1:50021`、仮の声は「雨晴はう / ノーマル」です。エンジン未起動時は案内を表示し、別の声へ自動変更しません。

音声クレジット: VOICEVOX:雨晴はう。配信・動画公開時もクレジットを表示してください。

## PSD

今回の修正は描画処理です。絵や PSD は変更せず、既存の `koma_expression_motion_v15.psd` をそのまま使います。v14・v15 の納品済み PSD は変更していません。

- EXP フォルダーを 1 個だけ表示します。すべて非表示にすると元の通常表情です。
- 各表情には左右の目と口の `.open` / `.closed` があり、同じ部位では片方だけ表示します。
- `face_plate.brows_cheeks` は眉・頬と描画下地です。
- 元の 66 レイヤーと元のニュートラルの画素を保持しています。
- PSD は描かれた開閉の両端の状態を保存します。口の中間形状と表情切り替えのタイミングは実行版で作ります。

## 動画サンプルの読み方

今回の動画は、実行版と同じ表情遷移・まばたき・口の変形・音量計算・身体リグの処理を使って OpenGL で新たに描画したプレビューです。操作画面の録画ではありません。

保存済みの VOICEVOX 音声を再使用しており、新しい台詞の音声合成はしていません。全表情で音声に合わせた口の動き、まばたき、切り替えと待機・発話の動作を確認する見本です。

## 検証範囲と制約

- 旧版と修正版を同じ音声・同じ頭と身体の動きで比較します。左右の傾きと複数の口の開きを、通常を含む 8 表情すべてで確認します。
- 絵と PSD の保存画素は旧版から変更していません。
- 表情連打、モードの競合、停止・一時停止・再開、古い音声の通知、通信終了を自動テストします。
- この環境ではブラウザー起動が制約で失敗するため、実ブラウザーの E2E は未実施です。ブラウザー用の回帰テストは同梱リポジトリに残しています。
- 実機カメラ / マイク、OBS、Photoshop 本体での操作は未確認です。
- 正式な Live2D Cubism モデルではなく、PSD 素材を独自の WebGL 2D メッシュで動かす実行版です。
- 音素別の「あいうえお」口形状、LLM 接続、髪の物理演算は未対応です。

- 以前からの脚部切り抜き・髪の外周マットは今回の範囲外で、変更していません。
