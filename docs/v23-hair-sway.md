# 羽月こま v23：毛先の揺れを大きく

ユーザーの「髪の揺れはもっと大きく揺れていい」に合わせ、v22の顔・腕・衣装・素材を保持して髪の動きだけ調整した。基準コミットは `d7d37e37647a114b13476176145ccce9b239d4e9`、ブランチは `codex/koma-v23-hair-sway`。

## 調整内容

後ろ髪の毛先の振幅を2.15倍、横髪の外側を2倍、内側・手前を1.65倍に設定。増幅量は根元で0、毛先へ向かって滑らかに増える。横髪は顔の際を守るため元画像座標y=460より下だけで増幅する。後ろ髪と左外側の横髪は重なりの隙間を防ぐためy=560より下に限定し、左外側はy=660へ向かって増幅する。前髪はv22と同じ。

後ろ髪のばね応答速度を0.82倍にして遅れと余韻を増やした。房ごとの速度・位相差と臨界減衰は保持。横髪の減衰速度を変えると顔の際の移動も変わるため、横髪は元の速度を維持した。根元は固定、固定顔面の頂点は動かさない。

10秒の同一入力で測定した毛先の最大水平変位（原寸1086×1448上）：

|---|---:|---:|

| 後ろ髪・右外 | 12.25 px | 25.82 px |
| 横髪・左外 | 6.07 px | 12.14 px |
| 横髪・右外 | 7.52 px | 15.05 px |
| 横髪・左手前 | 6.44 px | 10.63 px |

## 確認と成果

- `assets/parts/v23/review/koma-v22-v23-hair-comparison.mp4`：同じ時間・同じ顔向き・同じ腕の動きでv22/v23を横並び。白背景2列と黒背景2列。H.264、1600×560、約9.7秒。実ヘッドレスChromeで収録し、0・1・2・4・6・8・9.5秒を再デコードした。
- `review.json`：ページエラー0、根元の変位0。全8表情の顔テクスチャ全体のRGBA差0。顔の形状と目・口の描画は同じコード・素材を使用する。
- `head-v22-*.png`、`head-v23-*.png`：0〜10秒を0.5秒刻みで21組。`hair-pair-*.png` は拡大比較。`alpha-audit.json` は透明部分の診断。
- Nodeテスト165件成功。毛先の振幅、根元の固定、房別の遅れ、入力停止後に静止形状へ収まることを検証した。腕・胴体・スカートの既存テストも成功。
- 実装変更は `runtime/web/hair-rig.js` のみ。画像、モデル設定、腕・顔・衣装コード、PSDは変更していない。引き続きv22の `koma_articulated_v22.psd` を使用する。

白黒背景の連続比較で、顔の変形や髪全体が二重に残る状態は見られなかった。21時点すべてで顔周辺の新しい透明画素は0。初期調整では左横髪の重なりに253画素の細長い隙間が生じたため、増幅を始める位置を下げて抑えた。`initial-seam-diagnostic.png` はその修正前の記録。最終版の閉じた透明領域の新規画素は各時点0〜31画素で、大きな穴の増加は目視では認めなかったが、境界の画素差を完全にゼロにはしていない。

v22以前からある髪の白マットと細い透明境界は未修正。揺れる髪の輪郭が変わるため透明画素の位置も変わり、診断値だけで欠陥の有無は断定しない。比較画像・動画と数値を合わせて確認する。

起動は従来と同じ `Start-Koma.ps1` または既存Pythonで `runtime/server.py`。配布ZIPには既存の実行コードと必要画像を入れ、Python・音声／会話エンジン・AIモデル・認証情報は含めない。新規インストールも行わない。
