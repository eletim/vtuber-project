# 羽月こま v24：身体の動きが髪を動かす

v23 `89fcc5aa35174928d6f3ec0b8d08ddddf9fddf40` を保持し、`codex/koma-v24-expressive-motion` で制作。追加指示に従い12房を基本のまま残し、パーツ数ではなく身体の大きな動きと髪の追従を改善した。

## 素材と所有範囲の確認

12房は既存PSDの独立グループとしてすべて存在し、runtimeでは各房が別の60×80グリッド（4,941頂点）を所有していた。固定顔の髪除去マスクも維持されている。一部の房では設定上の毛先が実際の画像の下端より遠く、強い変形が画像外で起きていた。v24は実画像の下端をしなりの終点として扱う。確認記録は `assets/parts/v24/source-inspection.json`。

画像の追加分割・新規生成は不要と判断した。顔・目・口・肌・衣装・腕・髪のPNG、モデル設定、PSDはv23と同一。PSDは引き続き `assets/parts/v22/koma_articulated_v22.psd`、SHA256は `b159cbc45f04e835f4aa56fa3f28fcea35eea4e1906033c9a861f1d0b2907ce3`。

## 動き

身体の横移動は最大4pxから28pxへ拡大。腰と足元を固定したまま、肩・胸・頭の重心移動と胴の傾きを使う。全画像の平行移動だけではなく、腰へ向かう変形の減衰、頭の遅れ、独立した両腕の追従を組み合わせた。顔を含む上部の回転は既存方式を保ち、顔幅を変える伸縮は加えていない。

新しい `ParamBodyBounce` は-1〜1。嬉しい演技では軽く沈む「ため」の後に2回弾み、休む。落ち着いた待機では弾まない。専用ばねを介して肩と上半身を動かす。実アプリの計測では沈み約4.9px、上昇約19.4px、左右移動約20.2px。腕には肩の変換を同じように伝え、腕の変形を胴体服へ逆流させない。

髪は頭の描画メッシュから速度・加速度を計測し、中間部と毛先の2段階のばねへ入力する。毛先の応答を遅くし、減衰を少し弱めることで、身体が停止した後にも振り返して収まる。房ごとに応答速度・振幅・左右の上下加速度への反応が異なる。静かな周期揺れは従来より大幅に抑え、動きの主因を身体へ移した。

根元、顔の際、既知の重なり境界は固定。短い右頬横の房と左外側の接続部は、追加の曲げを掛けず頭の動きに追従させる。すべての房を一律に激しく動かす構造にはしていない。

スカートは身体の左右移動・傾き・弾みの速度へ遅れて追従する。未描画の裾下を出さないため、既存の3px制限を維持した。弾んだ頭頂が画面端で切れないよう、描画に6%の画角余白を設けた。比較動画ではv23にも同じ余白だけを適用し、身体や髪のコードは基準コミットのものを使っている。

## 使い方

既存の実行方法は変更なし。`Start-Koma.ps1` で起動し `http://127.0.0.1:8766/` を開く。画面の雰囲気を「楽しそう」にして「しぐさを再生」を押すと、ためと弾みを確認できる。「身体・弾み」スライダーも追加。リセットで静止へ戻る。音声・会話モデルは不要。

## 検証

- Node168件、Python HTTPサーバー5件成功。頭の加速で髪が動き、停止後に正負をまたいで戻り、最終的に静止すること、顔幅の保持、根元固定、メッシュ非反転、腕・胴体の独立、裾3pxの上限を検証。
- 実ヘッドレスChromeで、静かな待機→大きな左右移動→停止→ためと嬉しい弾み→停止と余韻を連続収録。比較MP4とv24単独サンプルは約13.2秒。各動画7時点で再デコード成功。
- 23時点の原寸画像、8表情×左右の最大姿勢16画像を保存。全39画像でキャンバス端に触れる不透明画素は0。頭頂のクリップを解消した。
- 全8表情の顔テクスチャ全体はv23との差0。口元の肌を含む元画像と表情差分を保持。新しい顔変形や肌の黒ずみは目視で認めなかった。
- 実アプリで「楽しそう」の演技とリセットを確認。ページエラー0、APIは新しい弾みパラメーターの上限とモード切替時の解除を確認。
- 停止後の例：9.2秒で身体を止め、10秒では髪の変位が約3.8px残り、11秒で約0.22px、12秒で約0.02pxへ減衰。これは静止診断の入力であり、通常待機では小さな揺れが残る。

記録は `assets/parts/v24/review/` の `review.json`、`app-verification.json`、`image-audit.json`、`motion-contact.png`、`expression-extremes.png`。肩・袖・口元・髪の境界・裾を白黒背景と原寸画像で確認した。

## 残る限界

v22以前からの髪の白いマットと脚の切り抜き、曲げ腕の途中姿勢の硬さは未修正。髪の細い境界差を完全に除去したわけではない。透明領域の診断には、袖と胴体の間の正当な空間や従来のマット穴も含まれるため、数値をそのまま欠陥数とは扱っていない。

身体の弾みは足元を固定した上半身の運動で、脚を曲げて離地するジャンプではない。裾の大きな翻りには追加の隠れ部分の作画が必要なため、今回は拡張していない。カメラ・マイク・新規音声合成は本変更の検証対象外。ユーザーの画面・入力は操作していない。ソフト／モデル導入、認証変更、mainマージは行っていない。
