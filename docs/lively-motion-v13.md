# VTuberらしい待機・発話の動き（v13）

今のPSDモデルと無料音声を使い、AI操作時の待機・発話に首と身体の動きを追加した。起動方法は [無料音声の手順](free-voice-v12.md) と同じ。

## 操作

- 「AI」に切り替えると、呼吸・まばたきに加えて首と身体がゆっくり揺れる。
- 「読み上げ」で実音量による口パクと、音量に応じたうなずき・首の動きが付く。
- 「発話の雰囲気」で、いつものこま／楽しそう／考え中／びっくりを指定できる。「仕草を試す」は4秒のプレビュー。
- 「自然な動き」をオフにすると、追加した首・身体・感情の動きが止まる。口パクと従来の呼吸・自動まばたきは独立。
- 人間操作のカメラ追跡・スライダーには追加モーションを適用しない。

楽しそうな仕草は軽い左右の揺れ・うなずきと目を閉じる動き、考え中は首かしげ、びっくりは短い顔の引き動作。既存の開閉目・口パーツを使用している。新しい口角や眉の描画、髪の物理演算は今回の変更に含まない。

## AIから指定

```python
from runtime.ai_client import KomaClient
koma = KomaClient()
koma.select('ai')
koma.say('一緒に楽しんでいきましょう！', emotion='happy')
```

```bash
python runtime/ai_client.py --say 'うーん、少し考えてみるね。' --emotion thoughtful
```

`POST /api/speech` は追加の `emotion` を受け付ける。`auto`（既定）は文章内の挨拶・喜び・思考・驚きの語から簡単なルールで選ぶ。会話AIが指定する場合は `happy` などを明示できる。

単独の仕草は `POST /api/performance {"emotion":"thoughtful","duration":4}`。モーション停止は `{"enabled":false}`。指定可能な感情は `neutral`, `happy`, `thoughtful`, `surprised`。継続時間は0より大きく30秒以下。

表情・仕草の開始時刻と終了時刻はサーバーの共有状態から受け取り、操作画面と配信画面が同じ周期で動く。基本姿勢へ小さな動きを加算して既存の可動範囲へ制限するため、AIからのポーズを保持できる。発話の雰囲気は実際の音声再生開始を待ち、WAVの残り時間に合わせて動く。一時停止・終了・合成失敗・操作モード切り替えで解除され、再開時は再生位置から復帰する。

## 検証

- Python：音声配信・停止・キャッシュ・モーション設定の入力検証とモード切り替え。
- Node：動きの可動範囲、口パク値の保持、無効時の外部ポーズ保持、感情の終了。
- 実VOICEVOX＋Chrome：発話・実音量の口パク・別配信画面への共有、考え中の仕草、自然な動きのオン／オフ、操作切り替え時の停止。
- 既存ブラウザE2E：カメラ／マイク入力、スライダー、配信画面、モバイル幅の回帰確認。

`assets/parts/v13/voice-verification.json` に実音声テスト結果を保存。確認動画 `koma-lively.mp4` は「待機2秒 → 発話約8秒 → 考え中3秒」。実際に動作確認した音声と同じWAVを使用し、同じモーション関数とWebGLモデルを15fpsで描画した比較用動画。操作画面の録画ではない。

音声クレジット：**VOICEVOX:雨晴はう**。音声生成・利用条件は [v12の手順](free-voice-v12.md#クレジット) を参照。

## 再生状態の共有（再開時の修正）

付属の操作画面は自動で `POST /api/playback` を送る。独自の音声プレーヤーを接続する場合は、`/api/speech` の返却値 `clip_id` を使い、`state`（`playing` / `paused` / `ended`）、`position`（秒）、`sequence`（その音声内で単調増加する0以上の整数）を送る。古い音声は409、古いsequenceは無視される。合成だけ完了してまだ再生されていない間は待機の仕草を維持する。
