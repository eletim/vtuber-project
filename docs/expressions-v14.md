- `expression_contact_sheet.png`: 通常・微笑み・にっこり・困り顔・驚き・照れ・不満・考え顔。

元のニュートラル表情、レイヤーの名前、レイヤーの画素、初期表示状態、元レイヤー同士の順序は維持しています。以前のファイルは上書きしていません。

## 表情切り替え

PSD の最上部にある `EXP` フォルダーを **1 個だけ表示**します。通常に戻すときはすべて非表示にします。
各フォルダーは眉・目・口・頬を合わせて描いたひとまとまりの顔差分です。独立した眉・眼球・口内のリグ用分割ではありません。

Photoshop では「ファイル → スクリプト → 参照」から同梱 JSX を実行すると、対象以外の表情を非表示にできます。元の `.open` を表示、`.closed` を非表示に戻します。保存や外部送信は行いません。Photoshop 本体での JSX 実行確認は未実施です。フォルダーの手動切り替えはスクリプト不要です。

従来の片目ずつの瞬き・口の開閉の 8 通りも維持しています。これらは EXP フォルダーをすべて非表示にした通常状態で使います。新しい顔差分と古い `.closed` を混在させないでください。

## 作成方法

承認済みの顔から `[340, 165, 740, 465]` を切り出した参照画像を編集対象とし、内蔵画像生成ツールで 7 枚の表情を個別に描きました。全身の再生成やコードによる代用の目・口の描画はしていません。

生の描画結果、完全なプロンプト、顔差分の合成範囲は `sources/` に保存しています。ビルダーは新しい絵を描かず、保存済みの描画を固定の顔領域に配置して PSD に格納します。生成画像の元 alpha は保存したまま、PSD の不透明な顔部分では古い目・口が透けないよう不透明な差分として置いています。

生成された全身 PNG、顔 PNG、一覧と GIF は、保存した PSD を再読み込みした結果と一致します。顔領域外と全身の alpha は元のままです。

## PSD 互換性

従来の独自 PSD 書き出しでは、保存プレビューと実際のレイヤー順が逆になる問題が確認されました。v14 では元レイヤーの意図された上下関係を維持しつつ、PSD 標準の記録順と Unicode フォルダー名を使用しています。旧書き出し関数と旧 PSD は変更していません。

独立した psd-tools の実レイヤーレンダリングで検証します。保存プレビューだけを比較する検査ではありません。通常の整数合成は元の画素と完全一致し、psd-tools の浮動小数点合成とは最大 1/255 の丸め差があります。最終的な各状態の数値は `independent_validation.json` を参照してください。

## 再生成・検証

```sh
python scripts/build_expressions_v14.py
python tests/test_expressions_v14.py -v
python tests/test_psd_groups_v14.py -v
python scripts/validate_expressions_v14.py
```

独立レンダリングには任意の検証依存 `psd-tools` が必要です。ビルダーは NumPy、Pillow、SciPy とプロジェクト内の PSD ヘルパーだけを使用します。保存した元画像から再生成できるため、画像生成ツールの再実行は不要です。
