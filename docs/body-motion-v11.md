# v11 — 身体のつながりと動き

## 変更

v10は全身テクスチャに横方向の歪みを加え、頭の傾きも胸元まで伝えていた。
身体・衣装・髪が同じ板として動く印象を減らすため、動かし方を変更した。

- 腰 `(543,1000)` を支点に、胴体を回転させる。下半身中央は固定する。
- 頭は首 `(540,425)` を中心に動き、肩の高さまでに影響を減らす。顔の絵は継承。
- 袖・腕・手のPSDレイヤーから左右の影響範囲を作る。手先まで胴体の親変換を伝え、腰の高さで腕だけ固定される状態を避ける。
- 肩と前腕に減衰した追従を加え、身体が動く/反転する際に腕が少し遅れる。
- 呼吸は胸郭中心の小さな変形と肩の上下に限定する。
- 髪の揺れは実際の横髪/後ろ髪の範囲に限定する。
- メッシュは60×80、4,941頂点。共有メッシュを動かすので、首・肩・腕を切り離した穴を作らない。

`runtime/model/skinning.json` はPSDから再生成する4つの影響度（左右腕、長い髪、腕の親追従）。
`runtime/web/body-rig.js` が姿勢と追従を計算し、WebGLへ頂点を送る。
PSD本体、顔・表情のPNG、ベース画像の画素とファイルは変更していない。
身体の描き直しや、正式なCubismのボーン/物理データ作成を行ったという報告ではない。

## 検証

```bash
python scripts/export_runtime_model.py
node --test runtime/tests/*.test.js
python tests/test_integrated_v10.py
```

- 通常姿勢で頂点が元座標と一致。
- 頭だけ傾けたとき、胸の中央が頭に引っ張られない。
- 下半身中央は固定しつつ、手先は肩・身体の変換に追従する。
- 240フレームの範囲端・反転入力でも、全三角形の向きと面積を保持。最小面積は基準三角形の25%より大きい。
- 腕の追従量が範囲内で、反転時に遅れて動く。
- 統合PSD/8表情/ランタイム画像座標の検査は継続合格。
- 実Chrome E2Eで表示・人間/AIの入力・顔追跡・音声・配信用オーバーレイを再確認。

修正前後の比較は `runtime/tests/body-motion.e2e.mjs` で取得する。
