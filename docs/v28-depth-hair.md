# v28: 腕の奥行き投影と髪の白マット修正

基点は v27 `58cfe626d254cc4262749c75d612bb33637fcca9`。旧PSD・PNG・履歴を保持する追加版です。

## 変更

- 肩・肘・手首の階層に前後方向の角度を追加。腕を上げる途中は前腕の長さ方向だけを短縮投影し、断面幅を維持します。上腕にも小さな前方挙上を加えます。前腕・手は共通の手首変形と投影を使い、手指の投影切替は積分した連続スケールとして元の長さ以上に伸ばしません。腕は胴体の前を通り、前腕・袖・手の既存描画順を維持します。
- 左右の重心移動を36pxから48pxへ、骨盤傾斜と胸の逆回転・左右腿の役割差も拡大。胴体の縦スケールは導入していません。右袖の内側接続は局所的な腕回転を固定し、外側に追従を残します。
- 髪の加速度・速度に対する応答を増加。後ろ髪外側の上限22→38px、前側の長い横髪10→20px。尾側の減衰を調整し、身体停止後も収束する追従を維持します。
- 白い塊は元のPNGに不透明画素として含まれており、WebGL合成による発生ではありません。PSD由来レイヤーの白マットを、近傍の髪色と白背景の混合としてアルファへ戻しました。顔・首・飾りの保護領域と前髪ハイライトは変更していません。8表情の固定頭部と動く髪のPNG、PSDを同じデータに揃えました。

## 残る制約

これは2.5Dの正面イラスト投影であり、完全な3D腕や手の裏面ではありません。袖の折れと手の向きの選択肢は既存ポーズ素材に制限されます。別方向を大きく見せるには、前から見た短縮上腕・肘内側・手の甲/掌の追加ポーズ作画が必要です。

白い塊は除去しましたが、元マットの細かなギザつきや房の重なりにある荒れは残ります。黒縁で埋めてはいません。12房を保持し、短い右前横髪と左外横髪は既存の接続保護範囲に収まるため局所スプリング変形を行わず、頭の動きに追従します。他10房は遅れを持ちます。

膝・足先・隠れたスカート内側の追加素材はありません。上下動は全身の重心移動、腿は可視範囲の回転、裾の追加遅れは3px上限です。元から存在する脚画像の切り抜き穴は今回の対象外で残ります。全身の大ジャンプを再現したものではありません。

外部アップロード、モデル導入、認証変更、mainマージは実施しません。
