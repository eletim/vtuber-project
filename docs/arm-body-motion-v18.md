# 羽月こま v18: 話すときの腕と身体の仕草

## 追加内容

話すときの小さな腕の仕草、肩の上下、上半身の姿勢変化を追加しました。音の細かい振幅ごとに手を振るのではなく、発話のまとまりに合わせた控えめな動きです。発話が止まると自然に静まり、待機中はゆっくりした姿勢変化と呼吸に戻ります。

袖・腕・手は同じ変形面でつながったまま動かします。元の絵を描き換えたり、手を大きく上げる別ポーズへ切り替えたりする機能ではありません。

## 起動と試し方

Python 3.10 以降と WebGL 対応の Chrome / Edge を使用します。

1. 実行用 ZIP を展開し、`koma-v18-runtime` フォルダーでターミナルを開きます。
2. `python -m pip install -r requirements-runtime.txt` を実行します。
3. `python scripts/run_runtime.py` を実行します。
4. ブラウザーで `http://127.0.0.1:8766/` を開きます。
5. 「音声ファイルでリップシンク」で `samples/koma-free-voice.wav` を選びます。AI 操作に切り替わり、実際に音声を再生して口と身体が動きます。

macOS / Linux で `python` が見つからない場合は `python3`、Windows では `py` を使ってください。初回のみ顔追跡のモデル / WASM を取得し、固定した SHA-256 で検証します。カメラ・マイクはボタンを押したときだけ開始します。

「自然な動き」を無効にすると、自動の仕草は静まります。手動・外部入力は引き続き使用できます。音声停止・一時停止・モード変更後に前の発話の仕草が続かないことを確認しています。

スライダーから左右の腕、肩、身体の重心も調整できます。外部からの HTTP / WebSocket 操作では、次のパラメーターを使えます。すべて `-1` から `1`、通常は `0` です。

- `ParamArmLOpen`: 画面左の腕。正の値で外側。
- `ParamArmROpen`: 画面右の腕。正の値で外側。
- `ParamShoulderY`: 正の値で肩を上げる。
- `ParamBodyShiftX`: 正の値で上半身の重心を画面右へ。

手動の値には安全な範囲で自動の仕草が重なります。厳密な手動ポーズにしたい場合は「自然な動き」を無効にしてください。

音声がブラウザーの自動再生制限で止まった場合は、画面内プレーヤーの再生ボタンを押してください。新しい文章を読み上げるにはローカルの VOICEVOX エンジンが別途必要です。

音声クレジット: VOICEVOX:雨晴はう。配信・動画公開時もクレジットを表示してください。

## 顔と PSD は v17 を保持

最新の PSD は引き続き `koma_expression_skin_v17.psd` です。今回の変更は動かし方だけで、新しい絵や PSD レイヤーを追加していません。承認済みの顔・口の肌補正・衣装・身体の画素、表情の切り替え方を保持しています。

- 通常を含む 8 表情を選択できます。
- まばたきは描かれた開眼・閉眼の 2 状態です。まぶたの連続変形ではありません。
- 口は v16 の方向補正と v17 の肌補正をそのまま使用します。
- PSD の切り替えは `artwork_controls/使い方.txt` を参照してください。

## 動画と検証の範囲

動画は同じ保存済み音声を使った 42 秒の新しいプレビューです。腕・肩・身体を見やすい全身表示で確認できます。新しい台詞の音声合成はしていません。

実行版と同じ JavaScript の仕草・口・身体リグの計算を使ったオフライン OpenGL 再描画であり、ブラウザー操作の録画ではありません。

- 身体の変形、動作の開始・停止・切り替え、旧表情と肌色の回帰を自動検査します。
- 元画像・PSD・モデル・口の描画処理は v17 とファイル単位で照合します。
- この環境では実ブラウザー E2E、実機カメラ / マイク、OBS、Photoshop 本体の操作は未確認です。
- 正式な Live2D Cubism データではなく、PSD 素材を独自の WebGL 2D メッシュで動かす実行版です。
- 元のポーズ内での控えめな腕の仕草です。手指の個別操作、大きな腕上げ、身体の向きを大きく変える動作は含みません。
- 以前からの脚部切り抜き・髪の外周マットは今回も変更していません。
